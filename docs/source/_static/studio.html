1. Palette

Hue/luminance matrix

Rows are luminance levels; columns are your current hue choices. Click a cell to assign that column's hue to the row.

2. Hue order and plot identifiers

Move rows to change which hue receives each luminance level. Marker and linestyle are redundant identifiers for grayscale/monochrome output.

3. Live plot gallery

Choose a plot type. Every preview uses your current colors and identifiers. Preview is browser-rendered SVG; exported Python uses Matplotlib.
