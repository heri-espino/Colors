contrastcolors
==============

contrastcolors is a Matplotlib-oriented library for constructing
contrast-controlled color palettes, compensating transparent colors, exploring
hue/luminance grids, and applying publication figure styles.

The two main ideas are:

1. choose hues independently while controlling adjacent WCAG contrast ratios;
2. treat the rendered color, including alpha and background, as part of the
   color-design problem.
